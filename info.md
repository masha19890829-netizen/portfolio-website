# Masha Zhou — AI Game Producer Portfolio

## Overview

A modern, dark-themed portfolio website built with React + TypeScript + Vite + Tailwind CSS.

## Theme Colors

### Primary Palette
- Background: #0B0F1A
- Card Background: rgba(255, 255, 255, 0.04)
- Primary Text: #F1F5F9
- Secondary Text: #94A3B8
- Muted Text: #64748B

### Neon Accent Colors
- Neon Cyan: #00F0C8
- Neon Purple: #A855F7
- Neon Pink: #EC4899
- Neon Blue: #3B82F6
- Neon Orange: #F59E0B

## Typography

- Display: DM Serif Display, Noto Serif SC
- Body: Inter, Noto Sans SC
- Mono: Roboto Mono

## Key Features

- Canvas 2D particle constellation background
- Glitch text effects
- Typewriter animations
- 3D tilt cards with glare
- GSAP ScrollTrigger animations
- 3D carousel (CSS perspective)
- Pinned paper scroll effect
- Responsive design

## Build

```bash
npm install
npm run build
```

## Pages

1. **Home**: Hero, Metrics, Bilibili Banner, Career Timeline, Portfolio Gallery, Today Quest Gallery, 5050 Game Incubator, GitHub Projects, Paper Scroll, Manifesto, Archive Carousel, Lab Video
2. **About**: Bio, Education, Skills, Career Archive, Core Capabilities, Player Profile
3. **Projects**: Project list with details
4. **Research**: Research notes
5. **Workflow**: Workflow steps
6. **Contact**: Contact info
