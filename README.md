# Masha Zhou — AI Game Producer Portfolio

A modern, dark-themed portfolio website built with **React + TypeScript + Vite + Tailwind CSS**.

🔗 **Live Demo**: [https://amgs5ah7zquwg.ok.kimi.link](https://amgs5ah7zquwg.ok.kimi.link)

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS 3.4 + shadcn/ui
- **Animation**: GSAP ScrollTrigger, CSS keyframes, Canvas 2D particles
- **Icons**: Lucide React
- **Fonts**: DM Serif Display, Noto Serif SC, Inter, Roboto Mono

## Project Structure

```
src/
  components/      # Reusable UI components
  components/ui/   # shadcn/ui components
  sections/        # Page sections (Hero, Metrics, etc.)
  pages/           # Route pages (Home, About, Projects, etc.)
  data/            # Site data (projects, career, skills)
  hooks/           # Custom React hooks
public/
  images/          # Design images, textures
  portfolio/       # Game portfolio screenshots
  videos/          # Video assets
```

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is in `dist/` directory.
